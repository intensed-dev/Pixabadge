# Duotone Icons
Duotone Icons can have multiple colors.

Style them using CSS variables:
- `--duotone-base` Duotone layer 1
- `--duotone-primary` Duotone layer 2
- `--duotone-secondary` Duotone layer 3

Example:

```html
<svg class="icon">...</svg>

<style>
.icon {
    --duotone-base: #fff;
    --duotone-primary: #888;
}
</style>
```
